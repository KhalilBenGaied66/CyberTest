# data/

| Path | In Git | Contents |
|---|---|---|
| `ioc/local_iocs.seed.jsonl` | yes | Versioned lab seed for the local IOC mirror (inert fixture indicators only) |
| `ioc/threatfox_mirror.jsonl` | no | Generated by `scripts/refresh_ioc_mirror.py`; last-known-good kept on failure |
| `runtime/` | no | Default `SOAR_DATA_DIR`: cases, raw evidence (0600), audit ledger, SQLite state, tickets, notification outbox, block log |

Local IOC line format:

```json
{"type":"ip","value":"198.51.100.44","verdict":"malicious","confidence":90,"source":"lab-fixture","first_seen":"2026-10-01T00:00:00Z","expires_at":"2027-10-01T00:00:00Z","tags":["brute-force"]}
```

`type` is one of `ip`, `domain`, `url`, `sha256`, `email`, and `verdict` is `malicious` or `suspicious`. Expired entries are reported as `stale` and never score. Malformed lines are skipped with a load warning.
